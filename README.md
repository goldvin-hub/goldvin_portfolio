## ✨ Features

- 🎬 **Cinematic Scroll-Driven Canvas Animation:** 300-frame responsive canvas rendering tied to page scroll progress.
- 🎨 **Dark Noir Aesthetic:** Glassmorphic UI with vibrant Japanese typography highlights and micro-interactions.
- 🛡️ **Security Hardened:**
  - Content Security Policy (CSP) & `nosniff` headers.
  - Reverse-tabnabbing protection (`rel="noopener noreferrer"`).
  - Honeypot anti-spam defense & client submission rate-limiting.
  - Anti-Inspection and anti-tamper shields (right-click lock, DevTools shortcut blocks, asset drag protection).
- 📱 **Fully Responsive & Accessible:** Adaptive particle pools on mobile, `:focus-visible` states, and `prefers-reduced-motion` compliance.
- 🚀 **Zero Dependencies:** Pure Vanilla HTML5, CSS3, and JavaScript — lightning fast load times.

## 🚀 Quick Start & Local Preview

To run locally on your machine:

```bash
# Clone the repository
git clone https://github.com/goldvin-hub/portfolio.git

# Navigate into the project directory
cd portfolio

# Run with any static server (or PowerShell script)
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Then open your browser and navigate to `http://localhost:8080`.
